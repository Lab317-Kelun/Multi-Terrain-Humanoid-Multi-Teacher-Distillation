# 高度图接收和处理说明

## 概述

`videomimic_inference_real.cpp` 通过 ROS 订阅高度图包发布的话题，接收点云数据并处理成策略网络所需的高度图格式。

```

```

### 消息类型
```cpp

```

## 接收的信息

### 1. 点云数据（PointCloud2）

**内容**：
- 3D 点云坐标（x, y, z）
- 每个点代表地面或障碍物的高度信息
- 点云已经过 elevation_mapping 包处理，包含融合后的高度图数据

**消息字段**：
- `header.frame_id`：点云的坐标系（例如 `odom` 或 `map`）
- `header.stamp`：时间戳
- `width`, `height`：点云尺寸
- `fields`：点云字段（x, y, z 坐标）
- `data`：点云数据（二进制格式）

### 2. 详细处理步骤

#### 步骤 1：获取 TF 变换

```cpp
// 获取点云坐标系到 base 坐标系的变换
transform_cloud_to_base = tf_buffer_->lookupTransform(
    ROS_BASE_FRAME,           // "odom_corrected"
    msg->header.frame_id,      // 点云的坐标系
    now, 
    ros::Duration(0.1)
);

// 获取机器人本体到 base 坐标系的变换
transform_torso_to_base = tf_buffer_->lookupTransform(
    ROS_BASE_FRAME,            // "odom_corrected"
    ROS_TORSO_FRAME,           // "torso_link"
    now, 
    ros::Duration(0.1)
);
```

**作用**：
- 将点云从原始坐标系转换到统一的 base 坐标系（`odom_corrected`）
- 获取机器人本体位置和姿态，用于计算相对高度

#### 步骤 2：转换点云格式

```cpp
// ROS PointCloud2 -> PCL PointCloud
pcl::PointCloud<pcl::PointXYZ>::Ptr cloud(new pcl::PointCloud<pcl::PointXYZ>);
pcl::fromROSMsg(*msg, *cloud);
```

**作用**：将 ROS 消息格式转换为 PCL 库可处理的格式

#### 步骤 3：去除无效点

```cpp
// 去除 NaN 点
std::vector<int> indices;
pcl::removeNaNFromPointCloud(*cloud, *cloud, indices);
```

**作用**：过滤掉无效的点云数据

#### 步骤 4：坐标系转换

```cpp
// 将点云转换到 base 坐标系
pcl::PointCloud<pcl::PointXYZ>::Ptr world_cloud(new pcl::PointCloud<pcl::PointXYZ>);
Eigen::Affine3d transform_eigen_double = tf2::transformToEigen(transform_cloud_to_base);
Eigen::Affine3f transform_eigen_float = transform_eigen_double.cast<float>();
pcl::transformPointCloud(*cloud, *world_cloud, transform_eigen_float);
```

**作用**：将所有点云转换到统一的 `odom_corrected` 坐标系

#### 步骤 5：构建 2D KD 树

```cpp
// 构建 2D 投影的 KD 树（只使用 x, y 坐标）
pcl::PointCloud<pcl::PointXY>::Ptr cloud_xy(new pcl::PointCloud<pcl::PointXY>);
for(size_t i = 0; i < world_cloud->points.size(); ++i) {
    cloud_xy->points[i].x = world_cloud->points[i].x;
    cloud_xy->points[i].y = world_cloud->points[i].y;
}

pcl::KdTreeFLANN<pcl::PointXY>::Ptr kdtree_2d(new pcl::KdTreeFLANN<pcl::PointXY>());
kdtree_2d->setInputCloud(cloud_xy);
```

**作用**：
- 将 3D 点云投影到 2D（x, y 平面）
- 构建 KD 树用于快速最近邻搜索
- 提高高度插值计算效率

#### 步骤 6：更新高度图网格

```cpp
// 更新高度图网格
updateHeightmap(world_cloud, torso_pos_eigen, torso_rot_eigen, kdtree_2d);
```

**作用**：根据点云数据和机器人位姿更新 11x11 的高度图网格

## 高度图网格配置

### 网格参数

```291:301:videomimic_inference_real.cpp
#define GRID_X_SIDE_LENGTH 11        // X 方向网格点数
#define GRID_Y_SIDE_LENGTH 11        // Y 方向网格点数
#define GRID_X_RESOLUTION 0.1        // X 方向分辨率（米）
#define GRID_Y_RESOLUTION 0.1        // Y 方向分辨率（米）
#define ROS_BASE_FRAME "odom_corrected"  // Base 坐标系
#define ROS_TORSO_FRAME "torso_link"    // 机器人本体坐标系
#define KNN_K 3                        // K 近邻数量
#define KNN_MAX_DISTANCE 0.15          // 最大搜索距离（米）
#define KNN_DEFAULT_HEIGHT_OFFSET 0.85  // 默认高度偏移（相对于本体 Z）
```

### 网格布局

- **尺寸**：11 × 11 = 121 个网格点
- **覆盖范围**：约 1.1m × 1.1m（以机器人本体为中心）
- **分辨率**：0.1m/点
- **存储**：`Eigen::Matrix<float, 11, 11> heights_`

### 网格坐标系

- **原点**：机器人本体（`torso_link`）位置
- **X 轴**：机器人前方
- **Y 轴**：机器人左侧
- **高度值**：相对于机器人本体 Z 坐标的高度差（米）

## 高度插值算法

### IDW（逆距离加权）插值

```1167:1234:videomimic_inference_real.cpp
float interpolateHeightIDW(
    const Eigen::Vector2f& query_point_xy,      // 查询点（x, y）
    const pcl::PointCloud<pcl::PointXYZ>::ConstPtr& original_cloud,  // 原始点云
    float torso_z,                              // 机器人本体 Z 坐标
    const pcl::KdTreeFLANN<pcl::PointXY>::Ptr& kdtree_2d  // 2D KD 树
)
```

**算法步骤**：
1. 使用 KD 树搜索 K 个最近邻点（K=3）
2. 检查最近邻距离是否在阈值内（0.15m）
3. 使用逆距离加权计算插值高度：
   ```
   weight_i = 1 / (distance_i + epsilon)
   height = Σ(weight_i * height_i) / Σ(weight_i)
   ```
4. 返回相对于机器人本体 Z 的高度差

## 注意事项

1. **话题名称**：当前硬编码为 `/elevation_map_fused_visualization/elevation_cloud`，可能需要根据实际发布的话题调整
2. **坐标系**：确保 TF 树正确配置，特别是 `odom_corrected` 和 `torso_link` 之间的变换
3. **实时性**：点云处理需要一定时间，回调函数会记录处理耗时
4. **数据有效性**：如果点云为空或无效，会保持之前的高度图数据
5. **内存管理**：高度图矩阵在类成员中持续存在，每次回调更新
