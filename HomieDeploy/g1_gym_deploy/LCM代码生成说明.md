# LCM 代码生成说明

## 1. 安装 LCM 工具

LCM（Lightweight Communications and Marshalling）需要安装 `lcm-gen` 工具来从 `.lcm` 文件生成 Python/C++ 代码。

### Ubuntu/Debian 安装

```bash
# 安装 LCM 库和工具
sudo apt-get update
sudo apt-get install liblcm-dev lcm-tools

# 或者从源码编译安装
git clone https://github.com/lcm-proj/lcm.git
cd lcm
mkdir build && cd build
cmake ..
make
sudo make install
```

### 验证安装

```bash
# 检查 lcm-gen 是否安装成功
lcm-gen --help
```

## 2. 从 .lcm 文件生成 Python 代码

### 2.1 单个文件生成

```bash
# 进入 lcm_types 目录
cd HomieDeploy/g1_gym_deploy/lcm_types

# 生成 Python 代码
lcm-gen -p pd_tau_targets_lcmt.lcm

# 这会生成 pd_tau_targets_lcmt.py 文件
```

### 2.2 批量生成所有 .lcm 文件

```bash
# 进入 lcm_types 目录
cd HomieDeploy/g1_gym_deploy/lcm_types

# 生成所有 .lcm 文件的 Python 代码
for file in *.lcm; do
    lcm-gen -p "$file"
done

# 或者使用 find 命令
find . -name "*.lcm" -exec lcm-gen -p {} \;
```

### 2.3 生成 C++ 代码

```bash
# 生成 C++ 头文件和源文件
lcm-gen -x pd_tau_targets_lcmt.lcm  # 生成 .hpp 和 .cpp

# 或者
lcm-gen -c pd_tau_targets_lcmt.lcm  # 只生成 .hpp
```

## 3. 命令参数说明

### lcm-gen 常用参数

```bash
lcm-gen [选项] <输入文件.lcm>

选项：
  -p, --python         生成 Python 代码（输出 .py 文件）
  -x, --cpp           生成 C++ 代码（输出 .hpp 和 .cpp 文件）
  -c, --cpp-hpp       只生成 C++ 头文件（.hpp）
  -j, --java          生成 Java 代码
  -o, --output-dir    指定输出目录（默认在当前目录）
  -h, --help          显示帮助信息
```

### 示例

```bash
# 生成 Python 代码到指定目录
lcm-gen -p -o python_output pd_tau_targets_lcmt.lcm

# 生成 C++ 代码到指定目录
lcm-gen -x -o cpp_output pd_tau_targets_lcmt.lcm
```

## 6. 自动化脚本

### 创建生成脚本

```bash
# 创建 generate_lcm.sh
cat > generate_lcm.sh << 'EOF'
#!/bin/bash

# Python 端生成
echo "Generating Python LCM types..."
cd g1_gym_deploy/lcm_types
for file in *.lcm; do
    if [ -f "$file" ]; then
        echo "  Generating Python code for $file..."
        lcm-gen -p "$file"
    fi
done

# C++ 端生成
echo "Generating C++ LCM types..."
cd ../../unitree_sdk2/lcm_types
for file in *.lcm; do
    if [ -f "$file" ]; then
        echo "  Generating C++ code for $file..."
        lcm-gen -x "$file"
    fi
done

echo "Done!"
EOF

# 添加执行权限
chmod +x generate_lcm.sh

# 运行脚本
./generate_lcm.sh
```

## 7. 注意事项

### 7.1 不要手动修改生成的文件

生成的文件（`.py`、`.hpp`、`.cpp`）都有注释：
```python
"""LCM type definitions
This file automatically generated by lcm.
DO NOT MODIFY BY HAND!!!!
"""
```

**重要**：如果修改了 `.lcm` 文件，必须重新运行 `lcm-gen` 重新生成代码。

### 7.2 版本一致性

确保 Python 端和 C++ 端使用**相同版本**的 `.lcm` 文件生成的代码，否则消息格式不匹配会导致通信失败。

### 7.3 依赖关系

生成 Python 代码需要：
- `lcm-gen` 工具
- Python `lcm` 库（`pip install lcm`）

生成 C++ 代码需要：
- `lcm-gen` 工具
- LCM C++ 库（`liblcm-dev`）

## 9. 常见问题

### Q: 找不到 lcm-gen 命令？

**A**: 需要安装 LCM 工具：
```bash
sudo apt-get install lcm-tools
# 或者从源码编译安装
```

### Q: 生成的文件在哪里？

**A**: 默认在当前目录生成，使用 `-o` 参数指定输出目录。

### Q: 修改了 .lcm 文件后需要做什么？

**A**: 重新运行 `lcm-gen` 生成新的代码，并确保 Python 和 C++ 端都更新。

### Q: Python 和 C++ 的 .lcm 文件需要一样吗？

**A**: 如果它们要互相通信，**必须完全一样**，否则消息格式不匹配。

## 10. 完整工作流程

```bash
# 1. 修改 .lcm 文件（例如：添加新字段）
vim lcm_types/pd_tau_targets_lcmt.lcm

# 2. 生成 Python 代码
cd g1_gym_deploy/lcm_types
lcm-gen -p pd_tau_targets_lcmt.lcm

# 3. 生成 C++ 代码
cd ../../unitree_sdk2/lcm_types
lcm-gen -x pd_tau_targets_lcmt.lcm

# 4. 重新编译 C++ 项目（如果需要）
cd ../../unitree_sdk2/build
make

# 5. 测试
python3 -c "from lcm_types.pd_tau_targets_lcmt import pd_tau_targets_lcmt; print('Success')"
```
