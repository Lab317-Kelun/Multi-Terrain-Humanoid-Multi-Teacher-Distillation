# G1 机器人策略部署运行流程

## 一、程序启动流程

```
main() 
  └─> load_and_run_policy()
```

### 1. 初始化阶段（`load_and_run_policy()`）

```
load_and_run_policy()
  │
  ├─> 创建 StateEstimator(lc)
  │     └─> 订阅 LCM 消息：
  │         - "state_estimator_data" (IMU 数据)
  │         - "body_control_data" (关节状态)
  │         - "rc_command" (遥控器命令)
  │
  ├─> 创建 RCControllerProfile(dt, se)
  │     └─> 用于处理速度命令 [vx, vy, vyaw, height]
  │
  ├─> 创建 LCMAgent(se, command_profile)
  │     └─> 初始化：
  │         - 控制周期：50Hz (20ms)
  │         - 关节数：27 个
  │         - 策略输出：12 个动作（左右腿各 6 个）
  │
  ├─> se.spin()
  │     └─> 启动状态估计器的 LCM 订阅线程（后台运行）
  │
  ├─> HistoryWrapper(hardware_agent)
  │     └─> 包装历史观测（6 步历史）
  │
  ├─> load_onnx_policy(ckpt_path)
  │     └─> 加载 ONNX 模型，返回推理函数
  │
  ├─> DeploymentRunner()
  │     ├─> add_control_agent(hardware_agent, "hardware_closed_loop")
  │     ├─> add_policy(policy)
  │     └─> add_command_profile(command_profile)
  │
  └─> deployment_runner.run(max_steps)
```

## 二、主控制循环（`DeploymentRunner.run()`）

### 2.1 初始化阶段

```
run()
  │
  ├─> agents[agent_name].reset()
  │     └─> LCMAgent.reset()
  │         ├─> actions = zeros(12)
  │         ├─> timestep = 0
  │         └─> get_obs() → 返回初始观测
  │
  └─> calibrate(wait=True)
        └─> 等待用户按 R2 按钮
        └─> 平滑移动到标称姿态（零位）
        └─> 等待用户再次按 R2 开始控制
```

### 2.2 实时控制循环（50Hz）

```
for i in range(max_steps):  # 主循环
  │
  ├─> action = policy(control_obs)
  │     │
  │     └─> load_onnx_policy 返回的推理函数
  │         ├─> 输入：control_obs (形状: [1, obs_dim * 6])
  │         │       包含 6 步历史观测
  │         └─> 输出：action (形状: [1, 12])
  │                 12 个动作对应左右腿各 6 个关节
  │
  ├─> obs = agents[agent_name].step(action)
  │     │
  │     └─> HistoryWrapper.step(action)
  │         └─> LCMAgent.step(action)
  │             │
  │             ├─> 动作裁剪：clip(action, -100, 100)
  │             │
  │             ├─> publish_action(action)
  │             │     │
  │             │     ├─> 动作缩放：action * 0.25 + default_dof_pos[:12]
  │             │     │
  │             │     ├─> 填充 joint_pos_target[:12] = scaled_pos_target
  │             │     │     (索引 12-28 保持为 0)
  │             │     │
  │             │     ├─> 创建 pd_tau_targets_lcmt 消息
  │             │     │     - q_des[29]: 29 个关节目标位置
  │             │     │     - tau_ff[29]: 29 个关节前馈力矩（全为 0）
  │             │     │
  │             │     └─> lc.publish("pd_plustau_targets", message)
  │             │           └─> 通过 LCM 发送给 C++ 程序 (g1_control.cpp)
  │             │
  │             ├─> time.sleep(20ms)  # 等待控制周期
  │             │
  │             └─> get_obs()
  │                   │
  │                   ├─> se.get_gravity_vector()
  │                   │     └─> 从 StateEstimator 获取重力向量
  │                   │
  │                   ├─> command_profile.get_command()
  │                   │     └─> se.get_command()
  │                   │         └─> 返回速度命令 [vx, vy, vyaw, height]
  │                   │
  │                   ├─> se.get_dof_pos()  # 获取关节位置
  │                   ├─> se.get_dof_vel()  # 获取关节速度
  │                   └─> se.get_body_angular_vel()  # 获取身体角速度
  │
  │                   └─> 拼接观测向量（91 维）：
  │                       - 速度命令 (4) * 缩放
  │                       - 身体角速度 (3) * 0.5
  │                       - 重力向量 (3)
  │                       - 关节位置误差 (27)
  │                       - 关节速度 (27) * 0.05
  │                       - 历史动作 (12)
  │
  │             └─> 返回观测
  │
  ├─> HistoryWrapper 更新历史
  │     └─> obs_history = concat([历史[1:], 新观测])
  │
  └─> control_obs = obs['obs_history']  # 用于下一轮策略推理
```

### 2.3 安全检查和紧急停止

```
每个控制循环中：
  │
  ├─> 检查身体姿态（rpy）
  │     └─> 如果 |roll| > 1.6 或 |pitch| > 1.6
  │         └─> calibrate()  # 紧急停止并返回零位
  │
  └─> 检查 R2 按钮
        └─> 如果按下
            └─> calibrate()  # 返回零位并等待
```

## 三、LCM 消息流

### 3.1 Python → C++（发布）

```
LCMAgent.publish_action()
  └─> lc.publish("pd_plustau_targets", message)
        └─> C++ 程序订阅 "pd_plustau_targets"
              └─> g1_control.cpp::handleActionLCM()
                    └─> 保存到 joint_command_simple
```

**消息内容**：
- `q_des[29]`: 29 个关节目标位置
  - 索引 0-11: 来自策略网络（左右腿各 6 个）
  - 索引 12-28: 当前为 0
- `tau_ff[29]`: 29 个关节前馈力矩（全为 0）

### 3.2 C++ → Python（订阅）

```
C++ 程序发布：
  │
  ├─> "state_estimator_data" (IMU 数据)
  │     └─> StateEstimator._imu_cb()
  │         └─> 更新：euler, R, imu_ang_vel
  │
  ├─> "body_control_data" (关节状态)
  │     └─> StateEstimator._bodydata_cb()
  │         └─> 更新：joint_pos, joint_vel
  │
  └─> "rc_command" (遥控器命令)
        └─> StateEstimator._rc_command_cb()
              └─> 更新：left_stick, right_stick, button_states
```

## 四、关键函数调用链

### 4.1 策略推理流程

```
DeploymentRunner.run()
  └─> policy(control_obs)
        └─> load_onnx_policy 返回的函数
              └─> ort.InferenceSession.run()
                    └─> ONNX 模型推理
                          └─> 返回 action[12]
```

### 4.2 动作执行流程

```
DeploymentRunner.run()
  └─> agent.step(action)
        └─> HistoryWrapper.step(action)
              └─> LCMAgent.step(action)
                    ├─> publish_action(action)
                    │     └─> lc.publish("pd_plustau_targets")
                    └─> get_obs()
                          └─> 从 StateEstimator 获取状态
```

### 4.3 状态更新流程（后台线程）

```
StateEstimator.__init__()
  └─> se.spin()  # 启动 LCM 订阅线程
        └─> 后台循环：
              └─> lc.handle()  # 处理 LCM 消息
                    ├─> _imu_cb()      # 更新 IMU 数据
                    ├─> _bodydata_cb() # 更新关节状态
                    └─> _rc_command_cb() # 更新遥控器命令
```

## 六、关键时间节点

1. **程序启动**：初始化所有组件，启动 LCM 订阅线程
2. **校准阶段**：等待用户按 R2，平滑移动到零位
3. **控制循环**：50Hz 实时控制
   - 每 20ms 执行一次：
     - 策略推理（~1-2ms）
     - 发布动作（~0.1ms）
     - 获取观测（~0.1ms）
     - 等待剩余时间

---

## 七、关键参数

- **控制频率**：50Hz (20ms)
- **策略输出**：12 个动作（左右腿各 6 个关节）
- **观测维度**：91 维（单步）→ 546 维（6 步历史）
- **LCM 通道**：
  - 发布：`"pd_plustau_targets"`
  - 订阅：`"state_estimator_data"`, `"body_control_data"`, `"rc_command"`
