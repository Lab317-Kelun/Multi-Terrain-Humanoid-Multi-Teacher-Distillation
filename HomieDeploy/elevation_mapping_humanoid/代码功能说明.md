## 核心模块功能

### 1. fast_lio_mid360（LiDAR-IMU 里程计）

**功能**：使用 MID-360 激光雷达和 IMU 数据进行实时里程计估计和建图

**主要文件**：
- `src/laserMapping.cpp`：主建图程序，实现 LOAM 算法
- `src/preprocess.cpp`：点云预处理
- `src/IMU_Processing.hpp`：IMU 数据处理

**关键功能**：
- **点云预处理**：去除异常点、降采样
- **特征提取**：提取边缘点和平面点
- **位姿估计**：通过迭代卡尔曼滤波估计机器人位姿
- **建图**：构建局部和全局地图

**输出**：
- `/cloud_registered`：注册后的点云（sensor_msgs/PointCloud2）
- `/odometry`：里程计信息（nav_msgs/Odometry）

### 2. elevation_mapping（高度图生成核心）

**功能**：从点云数据生成 2.5D 高度图

**主要文件**：
- `src/elevation_mapping_node.cpp`：ROS 节点主程序
- `src/ElevationMapping.cpp`：高度图映射主类
- `src/ElevationMap.cpp`：高度图数据结构和管理
- `src/RobotMotionMapUpdater.cpp`：机器人运动更新器

**关键功能**：

#### 2.1 点云处理流程

```cpp
// ElevationMapping.cpp::pointCloudCallback()
1. 接收点云消息
2. 获取机器人位姿协方差矩阵
3. 传感器处理器处理点云（坐标转换、噪声估计）
4. 更新地图位置（跟随机器人移动）
5. 运动预测更新（处理机器人运动带来的不确定性）
6. 将点云添加到高度图
7. 后处理并发布高度图
```

#### 2.2 高度图融合算法

```cpp
// ElevationMap.cpp::add()
对于每个点云点：
1. 计算点在网格中的索引
2. 检查该网格单元是否已有数据
3. 如果没有数据：直接使用测量值
4. 如果有数据：
   - 计算马氏距离判断是否为同一高度
   - 如果距离小于阈值：使用贝叶斯融合更新高度
   - 如果距离大于阈值：处理多高度情况（可能是障碍物）
5. 更新高度、方差、颜色等信息
```

#### 2.3 传感器处理器（Sensor Processor）

**功能**：处理不同传感器的点云数据

**主要类**：
- `SensorProcessorBase`：基类
- `LaserSensorProcessor`：激光雷达处理器
- `StructuredLightSensorProcessor`：结构光传感器处理器

**处理步骤**：
1. 坐标转换：将点云从传感器坐标系转换到地图坐标系
2. 噪声估计：根据传感器特性和位姿不确定性估计测量方差
3. 过滤：去除无效点（NaN、异常值等）

### 3. 辅助工具

#### 3.1 publish_tf.py

**功能**：发布静态坐标变换

**关键变换**：
- `torso_link` → `camera_depth_optical_frame`：相机到机器人本体
- `torso_link` → `lidar_link`：激光雷达到机器人本体
- `odom` → `odom_torso`：里程计坐标系转换

**作用**：建立完整的 TF 树，使所有传感器数据能够正确转换到统一坐标系

#### 3.2 pc_filter.py

**功能**：点云过滤

**处理流程**：
1. 订阅 `/cloud_registered` 点云
2. 将点云转换到 `torso_link` 坐标系
3. 过滤：去除 z 坐标大于阈值的点（去除机器人上方的点）
4. 发布过滤后的点云到 `/cloud_registered/filtered`

**作用**：去除机器人自身和上方的点，只保留地面点用于高度图生成

#### 3.3 publish_map_frame.py

**功能**：发布高度图坐标系

**处理流程**：
1. 监听 `odom_torso` 和 `torso_link` 的变换
2. 创建新的坐标系 `height_map`
3. 使用 `torso_link` 的位置，但只保留 yaw 角度（水平方向）
4. 发布 `height_map` 坐标系

**作用**：为高度图提供稳定的坐标系参考

#### 3.4 pose_publisher

**功能**：发布机器人位姿

**作用**：为 elevation_mapping 提供机器人位姿信息，用于：
- 更新地图位置（跟随机器人）
- 处理机器人运动带来的不确定性
- 坐标转换

## 高度图数据结构

高度图使用 `grid_map_msgs/GridMap` 消息类型，包含以下层（layers）：

- **elevation**：高度值（主要数据）
- **variance**：高度方差（不确定性）
- **horizontal_variance_x/y**：水平方向方差
- **color**：颜色信息（RGB）
- **time**：时间戳
- **lowest_scan_point**：扫描最低点

## 关键参数

### elevation_mapping 参数

- `mapFrameId`：地图坐标系（通常为 `odom`）
- `trackPointFrameId`：跟踪点坐标系（通常为 `torso_link`）
- `lengthInX/Y`：地图尺寸（米）
- `resolution`：地图分辨率（米/像素）
- `minVariance`：最小方差
- `maxVariance`：最大方差
- `mahalanobisDistanceThreshold`：马氏距离阈值（用于判断是否为同一高度）

### fast_lio_mid360 参数

- `lidar_topic`：激光雷达话题
- `imu_topic`：IMU 话题
- `map_file_path`：地图保存路径
- `publish_density`：发布密度

## 集成到策略网络

### 方法 1：通过 ROS 话题订阅

```python
import rospy
from grid_map_msgs.msg import GridMap
import numpy as np

class HeightMapSubscriber:
    def __init__(self):
        rospy.Subscriber('/elevation_mapping/elevation_map', GridMap, self.height_map_callback)
        self.height_map = None
    
    def height_map_callback(self, msg):
        # 提取高度层
        elevation_layer = None
        for i, layer_name in enumerate(msg.layers):
            if layer_name == 'elevation':
                elevation_layer = np.array(msg.data[i].data).reshape(
                    msg.data[i].layout.dim[0].size,
                    msg.data[i].layout.dim[1].size
                )
                break
        
        # 转换为策略网络所需的格式（例如 225 维）
        # 这里需要根据您的策略网络要求进行采样
        self.height_map = elevation_layer
```

## 注意事项

1. **坐标系一致性**：确保所有传感器和机器人本体的 TF 变换正确配置
2. **实时性**：高度图生成需要实时处理，注意计算资源
3. **内存管理**：高度图会占用一定内存，注意地图尺寸设置
4. **数据同步**：确保点云、位姿、IMU 数据时间同步
5. **参数调优**：根据实际环境调整方差阈值、地图尺寸等参数
